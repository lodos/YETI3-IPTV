# YETI³ IPTV для Mac

<img src="YETI3-IPTV-icon.png" alt="Иконка YETI³ IPTV" width="144" />

YETI³ IPTV — приложение для просмотра прямого эфира на Mac. В каталоге собраны каналы первого и второго российских мультиплексов. Плеер подключается к прямым источникам каналов. Для навигации доступны поиск, избранное и телепрограмма.

Требуется macOS 14 или новее. AirPlay позволяет вывести эфир на совместимое устройство.
