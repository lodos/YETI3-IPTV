# YETI³ IPTV для Mac

Приложение для просмотра прямого эфира на Mac. В каталоге есть каналы первого и второго российских мультиплексов. Доступны поиск по каналам, избранное и телепрограмма.

Версия 0.1.0. Требуется macOS 14 или новее. DMG подходит для Mac с Intel и Apple Silicon. Сборка подписана Developer ID, нотарификация Apple не выполнена.
